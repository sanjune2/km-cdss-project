# 강도 부정 문장 판정 기준

검토일: 2026-11-20

NORM-008 한 문장의 개발용 판정 기준을 최민준이 직접 확인했다. 기존 AFFIRMED 기준을 유지한다. 문맥 v3 모델의 UNCERTAIN 결과는 미해결 불일치로 남긴다.

## 확인한 사례

| 항목 | 내용 |
| --- | --- |
| 사례 ID | NORM-008 |
| 문장 | 기침이 심하지는 않아요. |
| 분류 대상 | 기침 |
| 원문 범위 | start 0, end 2. 끝 위치는 포함하지 않음 |
| 문맥 기준 | PATIENT_SYMPTOM |
| 존재 언급 기준 | AFFIRMED |
| 사용자 확인 | 기침의 존재를 언급하고 강도만 부정한다 |
| 검토 범위 | 해당 문장 1건의 프로젝트 라벨 정책 |

AFFIRMED는 문장 속 증상 존재의 긍정 언급을 분류하는 값이다. 실제 증상 존재·현재성·병명·심각도·처방 적합성을 임상적으로 확정하는 값이 아니다.

## 판정 이유

이 문장에서는 '심하다'는 강도를 부정하고 있다. 증상의 존재를 부정하거나 존재 여부를 모르겠다는 표현으로 분류하지 않는다는 기존 개발 기준을 유지한다.

이 판정은 지정 문장 전체에 대한 검토다. '심하지 않다'라는 부분 문자열만으로 모든 문장을 AFFIRMED 처리하는 규칙으로 일반화하지 않는다. 같은 문장에 존재 부정이나 불확실성 표현이 있으면 전체 문맥을 별도로 검토한다.

## 비교 표현

| 문장 | 개발 기준 | 구분 |
| --- | --- | --- |
| 기침이 없어요. | NEGATED | 증상 자체의 존재 부정 |
| 기침이 있는지 모르겠어요. | UNCERTAIN | 증상 존재의 불확실성 |
| 기침이 심하지는 않아요. | AFFIRMED | 이번에 확인한 강도 부정 사례 |

비교 표현은 기준 설명용이며 별도의 독립 평가 세트가 아니다.

## 모델 결과와 완료 범위

기존 기준 기록은 baseline/context_span_criteria_review_01.json의 NORM-008을 PATIENT_SYMPTOM / AFFIRMED로 두고 있다. 이 기준의 기존 검토자는 AI이며 당시 human_reviewed는 false였다.

저장된 context_gemma_context_v3_original12_01.json의 같은 사례는 PATIENT_SYMPTOM / UNCERTAIN이다. 이번 사용자 확인은 해당 문장의 기준 검토를 보완한 것이며, 과거 파일의 human_reviewed를 일괄 변경하거나 모델 결과를 AFFIRMED로 덮어쓰는 작업이 아니다.
