# 처방 검색 개발 검증 결과

검증일: 2026-11-20

처방 검색의 원문 연결, 응답 형식 변환과 로컬 E5 단일 실행을 확인했다. 실제 로그인·DB·화면·검색 이력 연결과 독립적인 추천 품질 평가는 남아 있다.

## 코드와 자료 범위

- 응답 변환 및 오프라인 검사: d0730d2
- 실제 E5 단일 검색 실행 도구: a9d4cdb
- 대상: AI 검색용 병증 44개, 연결 처방 417개, 처방약재 구성 3,648행
- 전체 처방 카탈로그 20,123개를 모두 검색·평가한 결과는 아니다.
- 원본 자료는 검사 전후 해시가 동일하다.

## 오프라인 구조와 응답 변환 검사

합성 입력 벡터·검사용 ID·검사용 원문 경로로 처방 417개와 약재 구성 3,648행의 보존을 확인했다. 잘못된 ID, 근거 누락, 자료 부족 처방의 점수 부여 등 경계 검사 15개를 통과했다.

이 검사에서는 DB·모델·네트워크를 호출하지 않았다. 검사에 사용한 ID와 원문 경로는 실제 서비스 요청에 사용할 수 없다.

## 원문 근거와 약재 연결 확인

이 실행에서 1위로 반환된 기업 처방 ID는 15510이다. 원문 위치 PRESP!D15511과 발췌문이 표시되고, 약재 구성 11개의 원본 용량·단위가 표시되는 것을 확인했다.

용량 수치는 원본 문자열로 보존한다. 환자별 투여량으로 환산하거나 적절한 복용량이라고 판단하지 않는다. 주의정보 상태는 RULES_NOT_REVIEWED이며, 환자별 주의정보 대조를 완료한 것으로 표시하지 않는다.

## 로컬 실행 시간

## 재현 명령

프로젝트 루트에서 기존 가상환경을 사용한다. 지정한 결과 파일이 이미 있으면 새 이름을 사용한다.

```powershell
.\.venv\Scripts\python.exe -B -m backend.scripts.run_prescription_search_preview `
  --data-root 'C:\km-cdss-data' `
  --symptoms '기침은 없고 배가 더부룩해요.' `
  --disease-id 84 `
  --output "$env:USERPROFILE\Documents\km-cdss-checks\prescription_review_replay_01.json"
```

원본 자료와 원문이 포함된 결과 JSON은 저장소 밖에 보관한다. 이 문서에는 재현 조건과 검사 요약만 기록한다.
